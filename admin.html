OHAENG ← 분석 위젯 미리보기

🛠 상품 관리

네이버 쇼핑커넥트·토스쇼핑 쉐어링크에서 직접 찾은 상품을 여기에 입력하면, 분석 위젯의 "평생 기본 아이템" / "지금 대운 시기 아이템" 추천에 그대로 반영돼요.
⚠️ 이 화면은 운영자용이에요. 방문자에게 이 페이지 링크를 직접 공유하지 마세요(홈페이지 메뉴에는 연결되어 있지 않아요). 입력한 내용은 이 브라우저에만 저장돼요 — 반드시 아래 "JSON으로 내보내기"로 파일을 받아서 사이트에 올려야 실제로 반영돼요.

➕ 상품 추가

네이버·토스 상품 페이지에서 상품 사진 우클릭 → "이미지 주소 복사"로 가져올 수 있어요. 일부 쇼핑몰은 외부 연결을 막아둬서 화면에 안 보일 수도 있어요 — 그럴 땐 자동으로 이모지로 대체돼요.
